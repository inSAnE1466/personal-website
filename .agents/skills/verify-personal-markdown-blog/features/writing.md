# Markdown writing

## Sub-features

The writing index lists published posts. The retained sample is a draft shown
only by the local preview, and its direct page demonstrates Markdown rendering.

## How to get to it (user POV)

Choose `Writing`, then choose a listed post. For local review, use the preview
mode so the draft sample is reachable.

## Driving it with the local browser

Run the helper, open `/writing/`, then `/writing/sample-formatting/`. Confirm the
title, date, headings, links, tables, draft notice, and `All writing` link.

## Gotchas

The normal public build excludes drafts. A missing sample route after a normal
build is expected, so use `npm run preview` for the mapped draft drive.
